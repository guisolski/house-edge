# Audio direction

## Soundtrack

Procedural synthwave with Brazilian rhythmic spice:

- Funk bass pulses
- Samba/forró-like syncopation in the loop accents
- Soft bossa-like chord color in higher blips

Implemented in `src/audio/synth.ts` via Web Audio oscillators (no external samples required).

## SFX

Distinct blips for move, interact, bet, win, lose, and UI.

## Options

Master volume + mute (keyboard `M`, menu toggle, gamepad select). Settings persist in save data.
